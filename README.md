# Arlix wireframe (www.arlix.art)

Static Next 15 export, hosted as a throwaway preview on Cloudflare Pages project `arlix-art-wireframe`.

Preview: https://arlix-art-wireframe.pages.dev

Redeploy after edits:
    cd /workspace/arlix-art-wireframe
    npm run build
    npx wrangler pages deploy out --project-name arlix-art-wireframe --branch main --commit-dirty=true

Local check (box only): npm run dev  (http://localhost:3000)
